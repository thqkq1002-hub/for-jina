# 2026년 모자보건사업 안내 검색 웹앱

보건복지부 발간자료 **"2026년 모자보건사업 안내"**(560쪽)를 키워드 클릭이나 검색으로 빠르게 찾아볼 수 있는 정적 웹앱입니다.

## 주요 기능

- **키워드 바로가기**: 사업명, 자주 찾는 항목, Q&A, 2026년 주요 변경사항을 카테고리별 칩으로 제공
- **전체 문서 검색**: 검색어를 입력하면 문서 전체에서 하이라이트된 결과와 챕터/쪽 정보를 보여줌
- **목차 탐색**: Ⅰ~Ⅸ 사업 영역과 세부 항목별 트리 탐색, 쪽 번호로 바로 이동
- **원문 뷰어**: 이전/다음 이동, 쪽번호 점프, 챕터/섹션 breadcrumb
- **AI 챗봇 (음성 지원)**: 우측 하단 채팅 버튼으로 자연어 질문 가능, 마이크로 음성 질문 지원(한국어). 관련 문서를 자동 검색해 근거 기반으로 답변하고 원문 쪽 링크를 함께 제공
  - AI 응답 기능은 Claude Artifact 환경(claude.ai)에서만 동작하며, 그 외 환경에서는 관련 문서 검색 결과로 자연스럽게 대체됩니다.
- 라이트/다크 모드 및 모바일 대응

## 구조

```
index.html          메인 앱 (단일 파일, 정적 HTML/CSS/JS)
data/app_data.json   목차·쪽번호 매핑·breadcrumb 데이터
data/app_pages.json  PDF 전체 560쪽 텍스트(레이아웃 보존 추출)
data/keywords.json   바로가기 키워드 목록
```

## 실행 방법

정적 파일이므로 별도 빌드 없이 그대로 정적 호스팅(GitHub Pages 등)하거나, 로컬에서 임의의 정적 서버로 열면 됩니다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 참고

- 표·서식 등 일부 복잡한 레이아웃(특히 세로쓰기 표 헤더)은 PDF 텍스트 추출 특성상 원문과 배치가 다르게 보일 수 있습니다.
- 검색 및 챗봇 답변은 참고용이며, 실제 업무 처리 시에는 원문 확인이 필요합니다.
